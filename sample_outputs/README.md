# Sample Outputs — VisiTrace

This directory contains representative outputs generated by running the actual Katomaran sample dataset video (`data/sample_videos/video_sample1.mp4`) through the VisiTrace pipeline.

## Contents

- `events/sample_stats.json`: Exported system KPIs, including total registered unique visitors, active tracks, and total verified entry and exit events.
- `events/sample_events.json`: Exported recent entry and exit event records with UTC timestamps, visitor IDs, visit IDs, detection confidence, and associated crop paths.
- `events/sample_visitors.json`: Registered visitor identities with first-seen, last-seen timestamps, total visit counts, and face crop quality metrics (without raw biometric embedding vectors).
- `events/sample_visits.json`: Session lifecycle records with entry timestamps, exit timestamps, and visit durations in seconds.
- `images/`: Directory structure for demonstration entry/exit crops.

## Privacy Notice

In compliance with biometric data privacy guidelines, runtime databases (`data/*.db`), raw embeddings, and actual runtime biometric recordings are excluded from public Git repositories via `.gitignore`. The files in this folder demonstrate schema structures and system verification data.
